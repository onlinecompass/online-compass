# 🧭 Online Compass — Free Browser-Based Navigation Tool

[![Website](https://img.shields.io/badge/Website-online--compass.com-blue?style=for-the-badge&logo=google-chrome&logoColor=white)](https://online-compass.com/)
[![Languages](https://img.shields.io/badge/Languages-46+-green?style=for-the-badge&logo=translate&logoColor=white)](https://online-compass.com/)
[![License](https://img.shields.io/badge/License-MIT-yellow?style=for-the-badge)](LICENSE)

A powerful, browser-based compass and navigation toolkit that works on any device with orientation sensors. **No app download required.** Just open your browser and start navigating.

> 🔒 **Privacy First:** All sensor data is processed locally on your device. We never store or track your location.

---

## ✨ Features

| Tool | Description |
|------|-------------|
| 🧭 **Live Compass** | Real-time compass showing North, East, South, West (0–360°) with True North correction |
| 🚗 **GPS Speedometer** | Track your travel speed in km/h or mph using browser GPS — no app needed |
| 🕋 **Qibla Finder** | Find the exact Qibla direction from any location using GPS coordinates |
| 🕉️ **Vastu Compass** | Align your home, office, or pooja room according to Vastu Shastra principles |
| ⛰️ **Elevation Tool** | Check your current altitude above sea level in real-time |
| 🧲 **Magnetic Declination** | Calculate the difference between True North and Magnetic North at your location |
| 📰 **Navigation Blog** | Expert articles on compass use, hiking, Vastu, Qibla, and digital navigation |

## 📦 Embed the Compass Widget

Want to add a live compass to your own website? Just copy and paste this code:

```html
<div class="embed-container">
  <!-- Live Compass Widget from Online-Compass.com -->
  <iframe 
    src="https://online-compass.com/embed" 
    width="100%" 
    height="400" 
    style="border:none; border-radius:16px;" 
    allow="geolocation; accelerometer; magnetometer"
    title="Online Compass Widget"
  ></iframe>
</div>
```

No API key needed. No signup required. Just embed and go.
