# Contributing to Online Compass

Thank you for your interest in contributing to Online Compass! 🧭

## How to Contribute

### 1. Report Bugs
If you find a bug, please [open an issue](https://github.com/onlinecompass/online-compass/issues) with:
- A clear description of the problem
- Steps to reproduce
- Your browser and device info

### 2. Suggest Features
Have an idea for a new tool or improvement? [Open an issue](https://github.com/onlinecompass/online-compass/issues) and describe your suggestion.

### 3. Submit Code
1. Fork this repository
2. Create a new branch (`git checkout -b feature/my-new-feature`)
3. Make your changes
4. Commit (`git commit -m "Add: my new feature"`)
5. Push to your fork (`git push origin feature/my-new-feature`)
6. Open a Pull Request

### 4. Improve Translations
We support 46+ languages. If you notice a translation error or want to add a new language, please open an issue or PR.

## Code of Conduct
- Be respectful and constructive
- Help others learn and grow
- Focus on solving real problems for users

## Questions?
Email us at: **contact@online-compass.com**

Thank you for helping make Online Compass better for everyone! ⭐
